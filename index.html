Sobre a estimativa TRI

O cálculo usa o modelo 3PL com D = 1,7, discriminação por nível (a = 1,30 / 1,50 / 1,70), acerto ao acaso c = 0,20 e busca MAP com prior N(0,1). Os valores de b são distribuídos dentro das faixas Z informadas para cada nível. Como os parâmetros não foram calibrados empiricamente com respostas de uma população, a nota é uma projeção didática — não uma nota oficial do Inep.
